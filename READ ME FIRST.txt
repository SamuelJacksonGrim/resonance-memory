RESONANCE MEMORY  —  a lasting memory for your local AI

START HERE (3 steps):

  1. Double-click  resonance-memory.exe
     Windows may say "Windows protected your PC" — that's SmartScreen
     being cautious about an unsigned program (certs cost money, not a
     hidden catch). Click  More info  →  Run anyway.
     A page opens in your browser. (No window pops up — that's normal.)

     macOS: do not double-click a downloaded copy. Right-click → Open →
     Open, or System Settings → Privacy & Security → Open Anyway.
     Then:  chmod +x  and run it. (xattr -d com.apple.quarantine  also works.)

  2. Click  "Connect"  next to your app (LM Studio or Claude Desktop).
     Using Claude Code, Cursor, Continue, Hermes, or another MCP app?
     Open the snippet on that page and paste it into the app's MCP config.

  3. Restart that app once.

That's it. Your AI can now remember things across conversations —
and nothing ever leaves your computer.

Your memories live in a file on THIS machine (nothing is uploaded):
  Windows:  %USERPROFILE%\.resonance-memory\resonance-memory.db
  macOS / Linux:  ~/.resonance-memory/resonance-memory.db
An older build stored this under ~/.lmstudio/ — first start copies it
here and leaves the original in place as a backup.
Export in the app is the backup. To move the store, copy that file
or use Export / Import.

One-time: on that page, if "Meaning engine" says "not set up," click
"Set up" (it downloads a small helper model in LM Studio, one click).
Without it, memory still works but matches on exact words, not meaning.

Curious what it does before connecting? Click "Show demo graph" on that page.

Full guide: open  README.md
To remove it later: double-click  uninstall.bat
  (that disconnects the app; it does NOT delete your memories)

Made by the Architect of Resonance. If it helps you, there's a Ko-fi link
in the app. Enjoy.
